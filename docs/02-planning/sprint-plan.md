## Ceremonies (solo-adapted Scrum)

| Ceremony | When | Solo adaptation |
|---|---|---|
| Sprint planning | First day, 45 min | Pick stories against measured velocity; write sprint goal in `sprint-log.md` |
| Daily stand-up | Each work session, 2 min | Three written lines in the learning journal: done / next / blockers |
| Backlog refinement | Mid-sprint, 30 min | Re-estimate, split, icebox triage |
| Sprint review | Last day, 30 min | Written review note **with evidence** (screenshots, test output, latency numbers) committed to `docs/02-planning/reviews/` |
| Retrospective | Last day, 20 min | Written: keep / drop / try. At least one process experiment per sprint |

## Definition of a successful sprint

The sprint goal is demonstrable (not "90 % done"), review note committed, retro written, risk register glanced at, README status table updated. That combination is exactly the evidence trail a Nordea steering group expects — in miniature.
